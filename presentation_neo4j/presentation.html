Contexte & Problématique

Le Constat

Les outils de gestion réseau grand public sont souvent :

  • Inexistants (Box opérateur basique)
  • Complexes (Ligne de commande, Nmap)

Notre Objectif

Créer une solution "All-in-One" accessible pour :

  • Visualiser le réseau (Graphique)
  • Sécuriser l'accès (Blocage)
  • Historiser les données (Neo4j)

Analyse & Spécifications

Besoins Fonctionnels

  • Scanner les IPs/MACs
  • Identifier les vendeurs (OUI)
  • Bloquer l'accès Internet
  • Générer des rapports

Contraintes Techniques

  • Langage : Python 3.10
  • OS : Windows (WinPcap/Npcap)
  • Performance : Scan < 5s
  • Base : Neo4j (Graphe)

Acteurs

  • Administrateur Réseau
  • Utilisateur Domestique
  • Système (Scan Auto)

Réalisation & Défis Techniques

Défi 1 : La Performance

Le scan séquentiel prenait 20 secondes.

Solution : Multithreading

Parallélisation des pings pour descendre sous les 3s.

Défi 2 : Blocage Fiable

L'ARP Spoofing est instable sur certains routeurs.

Solution : Boucle de Poisoning

Envoi continu de paquets falsifiés (toutes les 2s) pour maintenir l'attaque.

Modèle de Données (Neo4j)

Le Schéma

Device —[:DETECTED]→ Scan

Intérêt du Graphe

Permet des requêtes complexes comme :

MATCH (d:Device)-[:DETECTED]->(s:Scan) WHERE s.date > '2023-01-01' RETURN d
